# Piercer Batch File Renamer

Renomeador em lote com preview em tempo real, Regex, numeração e exportação de script

## Funcionalidades

- **Seções principais**: Regras de Renomeação, Preview Antes / Depois
- **Ações disponíveis**: Abrir Pasta (Direto), Aplicar na Pasta Aberta, Baixar Script PowerShell (.ps1), Baixar Script Bash (.sh)
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8116`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8116`.
